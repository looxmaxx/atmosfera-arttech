# Использованные инструменты, технологии и вклад команды

## 1. Собственный вклад команды
Вся архитектура продукта, правила единой визуальной системы и алгоритмы мультимодального синтеза разработаны командой с нуля на чистом JavaScript (ES Modules) без использования сторонних UI-фреймворков или готовых шаблонов:

1. **Мультимодальный анализатор (`js/analyze.js`):**
   * Локальный русскоязычный морфо-семантический анализатор текста с расчётом 5 эмоциональных осей (`valence`, `arousal`, `warmth`, `tension`, `nostalgia`), выделением цитаты и конструктором названий папок из 3–7 слов в едином тоне.
   * Попиксельный анализатор фотографий на Canvas (алгоритм k-means кластеризации для извлечения 5 доминирующих цветов, расчёт яркости, контраста, насыщенности и цветовой температуры).
   * DSP-аудиоанализатор на базе `Web Audio API`: детектор темпа (BPM) через автокорреляцию дифференциальной огибающей онсетов, определение тональности и лада (мажор/минор) методом Гёрцеля по 12 полутонам с корреляцией по профилям Крумхансла-Шмуклера, расчёт энергии (RMS) и спектральной яркости.
2. **Визуальная система и объяснимая логика (`js/visual-system.js`):**
   * Математическая модель перевода вектора `(Текст + Фото + Музыка)` в параметры композиции, ширину полей паспарту (`marginAir`), палитру, ритм смены кадров и выбор одного из 6 художественных приёмов.
   * Генератор пошаговой объяснимой логики (`[ТЕКСТ]`, `[ФОТО]`, `[МУЗЫКА]`, `[СИСТЕМА]`).
3. **Генеративный Canvas-рендерер и видеоэкспорт (`js/renderer.js`):**
   * Процедурная отрисовка 6 художественных стилей (мазки Моне, конструктивистская сетка Кандинского, декупаж Матисса, тушь и нити дождя Суми-э, плёночное гало Тарковского, лучи Фридриха) на холсте `720×1280` в 60 FPS.
   * Синхронная запись видео-воспоминания со звуком в формат `.webm` (`canvas.captureStream(30)` + `AudioContext.createMediaStreamDestination()` + `MediaRecorder`).
   * Процедурный WebAudio-синтезатор для озвучивания ритма и гармонии при вводе внешних ссылок на стриминги.
4. **Адаптивная озвучка и упаковщик Папки дня (`js/voice.js`, `js/zip.js`):**
   * Автоматический подбор тембра, скорости, тона и межфразовых пауз `Web Speech API` (`speechSynthesis`) под настроение дня + запись живого голоса с микрофона.
   * Собственная реализация упаковщика `.zip` (CRC-32, UTF-8 имена файлов) и прямое сохранение папки на диск через `File System Access API` (`showDirectoryPicker`).

## 2. Стандартные браузерные API и шрифты
* **HTML5 Canvas 2D API** — анализ пикселей фотографий и генеративный рендеринг страниц дневника.
* **Web Audio API** (`AudioContext`, `AnalyserNode`, `OscillatorNode`, `MediaStreamAudioDestinationNode`) — DSP-анализ аудиофайлов и реактивная визуализация звука.
* **MediaRecorder API & Canvas CaptureStream API** — экспорт готового видео-воспоминания со звуком (`.webm`).
* **Web Speech API (`speechSynthesis`)** — синтез речи для озвучки записи голосом, подобранным под атмосферу дня.
* **IndexedDB API** — локальное хранение архива дней, фотографий и аудио в браузере пользователя.
* **File System Access API** — сохранение реальной папки дня на диск пользователя.
* **Шрифты (Google Fonts, OFL):** `Cormorant Garamond` (заголовки папок), `Caveat` (рукописная цитата дня), `JetBrains Mono` (архивные штампы и метрики), `Manrope` (интерфейс).

## 3. Демонстрационные материалы и лицензии (Соблюдение п. 12 кейса)
* **Музыка (`demo/audio/*.wav`):** все 7 демонстрационных музыкальных треков процедурно синтезированы скриптом команды `tools/make_demo_music.py` (Python `wave` + `numpy`) специально для хакатона и переданы в общественное достояние по лицензии **CC0 1.0 Universal** (`demo/audio/LICENSE.txt`). При добавлении пользователем ссылок на Spotify / Яндекс.Музыку / YouTube чужие треки не копируются и не хранятся, а открываются через официальный встроенный плеер сервиса.
* **Фотографии (`demo/photos/*.jpg`):** 13 снимков сгенерированы моделью `gemini-3.1-flash-image` по авторским промптам команды (любительская мобильная съёмка без узнаваемых лиц и логотипов), 8 снимков взяты из свободной коллекции Unsplash (Unsplash License) и обработаны скриптом `tools/make_demo_photos.py`.
